# TravelLog

TravelLog is a personal, local-first macOS travel journal built with SwiftUI and SwiftData.

## Requirements

- macOS 14 or newer
- Xcode 16 or newer

## Run

Open `TravelLog.xcodeproj` in Xcode, select the TravelLog scheme, and press Run.

TravelLog stores its data locally. It has no accounts, analytics, cloud sync, or non-macOS targets.
