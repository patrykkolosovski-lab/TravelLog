# Map data

- `ReferenceLocations.json` contains the 193 UN member countries and the 17 UN
  Non-Self-Governing Territories used by TravelLog. Each record includes its
  continent and ISO two-letter flag code for statistics and location labels.
- `WorldMap.geojson` is Natural Earth's 1:50m Admin 0 map-units layer.
- `WorldMapTiny.geojson` is Natural Earth's companion tiny-countries layer.

UN reference sources:

- https://www.un.org/about-us/member-states
- https://www.un.org/dppa/decolonization/nsgt

Natural Earth source:

- https://github.com/nvkelso/natural-earth-vector

Natural Earth data is in the public domain.
